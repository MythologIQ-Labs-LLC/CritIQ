# Project Concept

## Why (One Sentence)

To create a screen capture and markup application that enables users to annotate screenshots with transcribed notes, generating visual evidence with metadata to guide AI coding agents in making precise UI adjustments.

## Vibe (Three Keywords)

1. Intuitive
2. Visual
3. Precise

## Anti-Goals (What This Is NOT)

- Not a general-purpose image editor like Photoshop or GIMP
- Not a complex video editing or screen recording suite
- Not a passive screenshot tool without annotation capabilities
- Not a tool that operates independently of AI-assisted development workflows
